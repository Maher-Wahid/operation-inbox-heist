# Outlook: Cosmic Crisis

An intergalactic adventure where Earth's communication systems are in danger!

The Mailorians have stolen the Cosmic Key, leaving Outlook offline. It's up to you, the Cosmic Explorer, to sneak into their base, retrieve the key, and fight your way back home!

## Play the Game

<!-- [**Click here to play Outlook: Cosmic Crisis!**](YOUR_GAME_LINK_HERE) -->

Start by cloning the repo. Then:

```bash
   cd operation-inbox-heist # Navigate to the project directory
   npm install # Install dependencies
   npm run dev # Run the application
```

Open your browser and go to `http://localhost:3000` (or whichever port your terminal outputs).

## How to Play

- Use **AD / Left/Right Arrow Keys** to move
- Press **E** to interact with objects and doors
- Find the hidden access code
- Collect the Cosmic Key
- Use **F** to throw your mighty rock and defeat the Mailorians!

## Your Mission

Retrieve the Cosmic Key, defeat the Mailorians, and bring Outlook back online!

**Earth is counting on you, Cosmic Explorer!**
